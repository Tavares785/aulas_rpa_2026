# Ficha de Avaliação de RPA

## Processo escolhido

Cenário A - Conciliação bancária diária.

## Regras claras

Sim. O processo utiliza regras fixas para comparar CNPJ e valor.

## Dados estruturados

Sim. Os dados do banco estão em um arquivo CSV e os dados do ERP possuem estrutura definida.

## Processo repetitivo

Sim. A conciliação é realizada diariamente seguindo os mesmos passos.

## Decisão subjetiva

Não. A comparação utiliza regras objetivas.

## Conclusão

O processo é adequado para automação com RPA, pois possui
regras claras, dados estruturados e atividades repetitivas.

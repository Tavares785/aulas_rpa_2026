Cenário: B

1. Nome do Processo
Triagem de solicitações de reembolso de despesas médicas

2. É viável para RPA? (Sim / Não)
Não

3. Justificativa baseada nos 4 critérios essenciais

- Repetitividade: O processo se repete, mas a forma de decisão muda a cada caso, pois depende da interpretação de quem avalia.

- Regras de Negócio: Não existem regras objetivas. O critério é "empatia e histórico emocional", algo subjetivo que não dá pra traduzir em lógica de robô.

- Tipo de Dados: Envolve dados não estruturados (relatos, contexto emocional). RPA funciona melhor com dados estruturados, como números e campos fixos.

- Volume: Mesmo com volume alto, isso não compensa a falta de regras claras — automatizar sem critérios definidos geraria decisões inconsistentes.

4. Mapeamento Passo a Passo das Ações do Robô
A decisão final depende de julgamento humano, então não é possível automatizar o processo por completo. O robô poderia atuar apenas em partes administrativas:

1. Receber a solicitação enviada pelo paciente.
2. Extrair os dados básicos do formulário (nome, data, valor, anexos).
3. Verificar se a documentação está completa.
4. Encaminhar o caso organizado para um analista humano decidir.
5. Registrar a decisão final no sistema.

O robô serviria só como apoio administrativo — a decisão continua sendo humana.

# 🤖 Automação Robótica de Processos (RPA) com Python

Bem-vindos ao repositório oficial da disciplina! Neste semestre, nossa jornada transformará vocês em Desenvolvedores de RPA preparados para os desafios reais do mercado de trabalho corporativo. 

Aprenderemos a construir "robôs de software" capazes de operar sistemas de forma autônoma, ler documentos e tomar decisões lógicas de ponta a ponta.

---

## 📚 Módulos e Roteiro de Estudos

### 🛠️ Módulo 1: Fundamentos de Python para Automação (Aulas 1 a 4)
Nesta etapa de nivelamento, vamos construir o alicerce da programação e garantir que nossos scripts não quebrem em produção.

**O que vamos dominar:**
* Configuração do ambiente profissional (Python, VS Code, Git e GitHub).
* Lógica de fluxo de controle (if, for, while) e estruturas de dados.
* Construção de robôs resilientes utilizando manipulação de arquivos externos, tratamento de exceções (`try/except`) e registro de logs da operação (`logging`).

**🔍 Para pesquisar antes das aulas:**
1. O que é e por que usamos controle de versão com Git/GitHub no mercado corporativo?
2. Como funciona a estrutura de blocos `try/except/finally` para tratamento de erros em Python?

---

### 🖱️ Módulo 2: Introdução ao RPA e Automação Desktop (Aulas 5 a 7)
Entraremos no universo do RPA aprendendo a dar "visão e movimento" aos nossos robôs em qualquer sistema operacional.

**O que vamos dominar:**
* Critérios corporativos para definir o que pode (e o que não deve) ser automatizado, aprendendo a documentar processos (PDD).
* Controle prático de mouse, teclado e mapeamento de tela utilizando a biblioteca **PyAutoGUI**.
* Execução de um projeto guiado de automação local com geração de evidências visuais (screenshots).

**🔍 Para pesquisar antes das aulas:**
1. Qual a diferença fundamental entre um robô de RPA e a Inteligência Artificial tradicional?
2. Como o sistema de coordenadas Cartesianas (X, Y) é aplicado na tela do seu monitor?

---

### 🌐 Módulo 3: Automação Web e Web Scraping (Aulas 8 a 10)
Sairemos do desktop e dominaremos a internet, interagindo com portais e extraindo informações vitais para os negócios.

**O que vamos dominar:**
* Controle de navegadores (Chrome/Edge) via código utilizando o **Selenium WebDriver**.
* Localização de elementos dinâmicos com **XPath** e **CSS Selectors**, e aplicação de Esperas Explícitas (*Explicit Waits*).
* Coleta massiva de dados invisível (*Web Scraping*) de páginas estáticas usando **BeautifulSoup** e **Requests**.

**🔍 Para pesquisar antes das aulas:**
1. O que é a estrutura DOM (*Document Object Model*) de uma página HTML?
2. Qual a principal diferença de arquitetura e velocidade entre automatizar com Selenium vs. BeautifulSoup?

---

### 📊 Módulo 4: Dados Corporativos e Integrações (Aulas 11 a 12)
O coração do back-office corporativo. Vamos processar arquivos pesados e conectar o robô com sistemas externos.

**O que vamos dominar:**
* Manipulação e consolidação de planilhas complexas com **Pandas** e **Openpyxl**.
* Leitura de arquivos PDF corporativos (**PyPDF2**) e mineração de padrões de texto (como CPFs, e-mails e faturas) usando Expressões Regulares (**Regex**).
* Consumo de APIs REST (formato JSON) e disparo automatizado de e-mails de notificação (**smtplib**).

**🔍 Para pesquisar antes das aulas:**
1. O que é o formato JSON retornado por APIs REST?
2. Como uma Expressão Regular (Regex) consegue encontrar padrões específicos (como números de telefone) perdidos no meio de um texto longo?

---

### 🏗️ Módulo 5: Arquitetura Avançada e Projeto Final (Aulas 13 a 15)
Elevando a engenharia de software do bot. Vamos aplicar arquiteturas escaláveis para lidar com alto volume de processamento e falhas de infraestrutura.

**O que vamos dominar:**
* Escalabilidade corporativa utilizando Filas em memória (**Queue**).
* Processamento concorrente/assíncrono (**asyncio**) e estratégias avançadas de tolerância a falhas (*Retry* e *Exponential Backoff*).
* Planejamento estruturado (documentação em Markdown) e execução prática de um **Projeto Final** de automação *end-to-end*.

**🔍 Para pesquisar antes das aulas:**
1. O que é programação assíncrona (concorrência) e por que ela é tão importante ao consumir várias APIs simultaneamente?
2. Como estruturar um excelente arquivo `README.md` no GitHub para destacar seu portfólio profissional em processos seletivos?
